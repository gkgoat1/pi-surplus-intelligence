## 2. What it means

The probe answered the plan's biggest open question early: x402 v2 is what
Surp actually sends (`amount`, `eip155:8453`, `payment-required` header), and
Surplus Intelligence speaks it too — with a facilitation fee, so API keys stay
the cheaper default there. Bu0y, OpenRouter, and Ruvicode are plain
key-gated 401s; Ruvicode's undocumented base URL resolved to
`https://api.ruvicode.com/v1` by probing. The payment core (parse, sign,
policy gate, single retry) is done and stub-proven, including the
never-pay-a-bare-402 rule, so the remaining phases are wiring, not research.

## 3. Still open

- The live settlement (C-6) needs a funded test wallet: no `x402-wallet`
  keychain entry, `~/keys` wallet file, or `X402_TEST_KEY`-style env var
  exists on this machine. Until one is supplied, Phase 1's proof is
  stub-level only.
- Phase 1's price ceiling is hard-coded at 0.25 USDC; real policy lands in
  Phase 4.
- Surp's retry header is assumed to be `X-Payment` (its docs say so, its
  challenge is v2-shaped); only a live run confirms which the server accepts.
